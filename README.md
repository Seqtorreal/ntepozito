# Ντεπόζιτο

Προσωπική εφαρμογή καυσίμων για iPhone (αμάξι και μηχανάκι). Είναι web app (PWA): μπαίνει στην αρχική οθόνη από το Safari, ανοίγει χωρίς τη γραμμή του browser, δουλεύει offline. Δεν χρειάζεται App Store ή συνδρομή Apple Developer.

**Διεύθυνση:** https://seqtorreal.github.io/ntepozito/ (GitHub Pages, branch `gh-pages`)

## Τι κάνει

- Νέο γέμισμα: αμάξι ή μηχανάκι, ποσό, λίτρα, τιμή λίτρου (γράφεις δύο και το τρίτο βγαίνει μόνο του), ημερομηνία, χιλιόμετρα, πρατήριο.
- Φωτογραφία απόδειξης: η εφαρμογή τη διαβάζει (ελληνικά και αγγλικά) και συμπληρώνει ποσό, λίτρα, τιμή και ημερομηνία/ώρα. Αν λείπει ένα από ποσό, λίτρα ή τιμή, το υπολογίζει από τα άλλα δύο. Η φωτογραφία αποθηκεύεται μαζί με το γέμισμα.
- «Δες τι διάβασε»: σάρωση πάνω στη φωτογραφία με όλες τις λέξεις που διάβασε. Κόκκινες είναι όσες διάβασε με βεβαιότητα κάτω από 60%, χρωματιστές αυτές από τις οποίες βγήκαν ποσό, λίτρα και τιμή, και ακολουθεί όλο το κείμενο ανά γραμμή με τη βεβαιότητά του. Χρησιμεύει για να φαίνεται πού κάνει λάθος η ανάγνωση.
- Μήνας: πόσα ξόδεψες, ανά όχημα, σύγκριση με τον προηγούμενο μήνα.
- Ιστορικό: όλα τα γεμίσματα ανά μήνα, με φίλτρο οχήματος. Πατάς ένα για αλλαγή ή διαγραφή.
- Στατιστικά 12 μηνών: έξοδα ανά μήνα, πορεία τιμής λίτρου, κατανάλωση λ/100 χλμ, κόστος ανά χιλιόμετρο, κάθε πόσες μέρες γεμίζεις.
- Αντίγραφο ασφαλείας: εξαγωγή σε αρχείο (Αρχεία ή iCloud Drive) και επαναφορά.

## Πού μένουν τα δεδομένα

Μόνο μέσα στο iPhone (IndexedDB της εφαρμογής). Τίποτα δεν στέλνεται σε server. Ο server φιλοξενεί μόνο τον κώδικα.

Προσοχή:
- Αν σβηστεί το εικονίδιο από την αρχική οθόνη, σβήνονται και τα δεδομένα. Γι' αυτό υπάρχει η εξαγωγή αντιγράφου· η καρτέλα Ρυθμίσεις βγάζει πορτοκαλί κουκκίδα αν περάσουν 30 μέρες χωρίς αντίγραφο.
- Η εφαρμογή στην αρχική οθόνη έχει δικά της δεδομένα, ξεχωριστά από το Safari. Ό,τι περαστεί στο Safari πριν την εγκατάσταση δεν μεταφέρεται.
- Η ανάγνωση απόδειξης κατεβάζει τον αναγνώστη κειμένου (μερικά MB) την πρώτη φορά, άρα θέλει internet εκείνη τη στιγμή. Μετά δουλεύει και offline.

## Πώς είναι ανεβασμένη

Το repo έχει όλο το project. Το GitHub Pages σερβίρει μόνο τον φάκελο `app/`, που ανεβαίνει στο branch `gh-pages`. Δεν χρειάζεται build.

## Μεταφορά στον κάτοχο

1. Ο νέος κάτοχος φτιάχνει δωρεάν λογαριασμό στο GitHub.
2. Στο repo: **Settings → General → Danger Zone → Transfer ownership** και γράφεις το όνομα χρήστη του. Εκείνος αποδέχεται από το email.
3. Η διεύθυνση γίνεται `https://<όνομα-χρήστη>.github.io/ntepozito/`. Η παλιά δεν ανακατευθύνει.
4. Τα γεμίσματα είναι δεμένα με τη διεύθυνση. Αν έχουν ήδη περαστεί γεμίσματα, πριν τη μεταφορά: **Ρυθμίσεις → Εξαγωγή αντιγράφου**, μετά εγκατάσταση από τη νέα διεύθυνση και **Επαναφορά από αντίγραφο**.

## Εγκατάσταση στο iPhone

1. Άνοιξε τη διεύθυνση στο **Safari**.
2. Πάτα **Κοινοποίηση** (το τετράγωνο με το βέλος) → **Προσθήκη στην οθόνη Αφετηρίας**.
3. Άφησε ενεργό το «Άνοιγμα ως εφαρμογή Ιστού» και πάτα **Προσθήκη**.
4. Άνοιξε το «Ντεπόζιτο» από την αρχική οθόνη και πέρασε τα γεμίσματα από εκεί.

## Ενημέρωση

Από τον φάκελο του project, αφού κάνεις commit στο `main`:

```bash
git subtree push --prefix app origin gh-pages
```

Αν άλλαξες κώδικα, άλλαξε και το `VERSION` στο `app/sw.js` (π.χ. `ntepozito-v8`), ώστε το iPhone να πάρει τη νέα έκδοση. Η αλλαγή φαίνεται από το δεύτερο άνοιγμα της εφαρμογής.

## Δοκιμή στον υπολογιστή

```bash
cd app && python3 -m http.server 8765
```

Μετά άνοιξε http://localhost:8765.

## Αρχεία

- `app/index.html`: σκελετός, tab bar
- `app/styles.css`: χρώματα, τυπογραφία (Commissioner), animations
- `app/app.js`: αποθήκευση, οθόνες, γραφήματα, φόρμα, ανάγνωση απόδειξης, αντίγραφα
- `app/sw.js`: offline λειτουργία
- `app/manifest.webmanifest`, `app/icons/`: όνομα και εικονίδιο αρχικής οθόνης
- `tests/parse.test.mjs`: τεστ ανάγνωσης αποδείξεων (`node --test tests/parse.test.mjs`)

Εικονίδια: [Phosphor Icons](https://phosphoricons.com) (MIT), ενσωματωμένα στο `app.js`.
